# ADR 003 — Limiar de reconhecimento

**Estado:** provisório.

**Decisão:** 0,40 é valor inicial apenas para demonstração. Selecionar o limiar por F1 macro na validação com pessoas desconhecidas. Usar teste somente na avaliação final.

**Consequência:** o valor obtido no LFW pode não transferir para a câmera, especialmente por diferença de alinhamento. A decisão de produção precisa de validação consentida local.
