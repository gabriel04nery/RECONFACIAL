# SPEC 002 — Cadastro

**Requisito:** cadastrar identidade com autorização, capturar somente uma face por quadro e armazenar embeddings.

**Aceitação:** nome validado; opção `--consentimento` exigida; quantidade >= 1; cadastro duplicado recusado; fotos não persistem.

**Verificação:** cadastro de teste, duplicação e inspeção dos arquivos locais.
