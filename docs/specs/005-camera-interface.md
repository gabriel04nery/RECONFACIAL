# SPEC 005 — Interface e exclusão

**Requisito:** exibir webcam, permitir parar com Q e excluir identidade sob solicitação.

**Aceitação:** `Q` fecha janela e libera câmera; `excluir --nome` apaga o cadastro no armazenamento ativo; ausência do nome retorna erro.

**Verificação:** testes operacionais com a webcam e inspeção do JSON; verificar backups manualmente.
